GOOD TO KNOW

开始之前，
你可能想知道。

它是网页版，还是桌面软件？+

这是 InstaCourse 刷课助手的产品介绍与下载网站。自动播放、章节切换和题库匹配等功能在 Windows 桌面程序中运行，网页演示不会操作真实课程。

需要什么运行环境？+

当前发布包面向 Windows x64。浏览器模式需要本机安装 Chrome 或 Edge；项目说明称缺少浏览器时可回退到内置窗口。macOS 与 Linux 尚未适配。

所有平台、所有课程都能用吗？+

不能保证。项目说明仅报告本地模拟课程页测试，未提供各真实平台的完整验证结果。页面结构、播放器与平台策略变化都可能影响功能，请先检查实际表现。

登录信息和题库保存在哪里？+

默认数据目录为 %APPDATA%\instacourse\，包含配置、题库、独立浏览器登录状态和 Cookie 备份。在线题库是可选功能，启用后会向你配置的接口发送题干。请妥善管理本地数据和备份。

使用时有哪些边界？+

请遵守课程平台协议及学校、单位规定。自动化功能可能不被平台允许；不要用于代考或替代本人应完成的考核。项目不提供人脸识别或活体检测绕过功能。

下载后为什么不能只拷走 EXE？+

这是文件夹式便携版，程序依赖同目录的 resources、locales 等运行文件。请保留完整解压目录。安装包未做代码签名，请自行核对来源；本站不提供已通过安全审计的承诺。
